For my CS-499 ePortfolio, I used my LCR Dice Game to demonstrate my software design and engineering skills. Working with an existing C++ project gave me the chance to review how the code was organized and make improvements while keeping the main purpose of the game intact.

The project uses separate files and classes for the game logic and player information. This organization helps keep different responsibilities separate and makes the code easier to follow. I also worked on integrating SQLite database functionality into the existing application, which required considering how the database class would work with the rest of the game.

One lesson I learned from this project is that adding a feature involves more than writing new code. The new functionality needs to fit into the existing structure without disrupting other parts of the application. Reviewing the code and testing changes helped me think more carefully about how the different parts work together.

This artifact aligns with Course Outcome 3 because I had to consider the existing design and make decisions about how to organize and extend the application. It aligns with Course Outcome 4 because I used programming tools and SQLite to expand the capabilities of an existing C++ project.

I included this artifact in my ePortfolio because it represents my experience improving an application rather than only creating something from scratch. These skills are important to my goal of working in game development, where code organization, maintainability, and the ability to add features are all valuable.
