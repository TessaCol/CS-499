#About This Project
This portfolio showcases my work in the Computer Science program and the skills I have developed throughout my degree. My capstone project is an LCR Dice Game written in C++.

#LCR Dice Game
LCR stands for Left, Center, Right. Players start with three chips and take turns rolling dice. The dice determine whether players pass chips to the left, pass them to the right, place them in the center, or keep them. The goal is to be the last player with chips remaining.

#Enhancements
For my capstone, I worked on improving my original dice game and exploring how to use an SQLite database with the program. The database design includes tables for players, games, turns, dice results, and chip movements.
This project helped me learn more about organizing C++ code, working with relational databases, and improving an existing program. Database integration is an area I am continuing to work on.
