For my CS-499 ePortfolio, I used my LCR Dice Game from IT-312 to demonstrate my database skills. The original game focused on running the game and keeping track of information while it was running. I enhanced the project by adding SQLite functionality so the application could work with a database.

One part of this enhancement was creating a database class to handle database operations. I added functions to open and close the database, create tables, and add players. I also created tables for games, players, turns, dice results, and chip movements. This helped me learn how to organize database information and connect database operations to an existing C++ application.

A challenge with this project was adding database functionality while keeping it organized with the existing game code. I had to consider how the database would fit into the application and how different pieces of game information could be represented in tables. Using SQLite with C++ gave me practical experience working with SQL statements and managing database connections.

This enhancement aligns with Course Outcome 3 because I had to make design decisions about how the database would organize information for the game. It also aligns with Course Outcome 4 because I used C++ and SQLite to expand an existing application with database functionality.

I included this artifact in my ePortfolio because it shows how I have developed my programming skills beyond the basic game logic. Working on the database gave me experience with database design, SQL, and connecting different parts of an application. These skills can help me build more complex applications as I continue working toward my goal of game development.
