For my CS-499 ePortfolio, I used my LCR Dice Game to demonstrate my skills with algorithms and data structures. One improvement I made was changing how the game stores its players. The original version used a fixed-size array that limited the number of players it could hold. I changed it to use a C++ vector so the player list could grow as needed.

This change required updating the parts of the game that set up players and use the player list during gameplay. I had to make sure the new data structure worked with the existing game logic. This helped me understand how changing one part of a program can affect other parts and why testing is important after making changes.

This enhancement aligns with Course Outcome 3 because I evaluated a limitation in the original program and chose a data structure that better fit the game's needs. Using a vector made the player list more flexible than the original fixed-size array.

I included this artifact in my ePortfolio because it shows how I can review existing code, identify a limitation, and make a practical improvement. These skills are useful for game development because programs need data structures that fit their requirements and can be maintained as the project grows.
